## 3. 화면을 끈 채 재생 (가장 중요)

| # | 할 일 | 확인 | 메모 |
|---|---|---|---|
| 10 | **3**회, 알림음 두 개 켬 → **▶ 시작** 직후 전원 버튼으로 화면을 끈다 | □ | |
| 11 | 화면이 꺼진 채로 소리가 끝까지 이어진다 | □ | |
| 12 | 화면이 꺼진 채로 3회차 **종소리**와 **완료음**이 들린다 | □ | |
| 13 | 화면을 켜면 `3회 완료` 화면이 보인다 | □ | |
| 14 | 다시 108회로 시작해 화면을 끄고, 잠금 화면이나 알림창의 재생 표시에서 `37 / 108` 같은 진행 상황이 보인다 | □ | |
| 15 | 잠금 화면의 일시정지 → 재생 버튼이 동작하고, 화면을 켰을 때 경과시간이 일시정지 시간만큼 멈춰 있었다 | □ | |
| 16 | **동영상 파일**로 시작해 화면을 끄면 소리가 계속 나고 횟수가 올라간다. 화면을 켜면 영상과 소리가 다시 맞는다 | □ | |
| 17 | 재생 중 다른 앱을 잠깐 썼다 돌아와도 횟수가 맞다 | □ | |
| 17-1 | **∞**로 시작해 화면을 끄고 들리는 횟수를 직접 센다(4번 이상). 화면을 켰을 때 숫자가 들은 횟수 + 1(지금 재생 중)과 같다 | □ | |
| 17-2 | 재생 중 뒤로 가기를 눌러도 멈추지 않고 "끝내려면 ■ 정지를 눌러 주세요"가 뜬다 | □ | |

화면을 끄면 재생이 멈춘다면: 앱 목록 화면 아래의 **"화면을 끄면 재생이 멈추나요?"** 안내대로 Chrome을 절전 예외로 두고 10번부터 다시 해 주세요.
